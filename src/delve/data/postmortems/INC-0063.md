# Postmortem: INC-0063

**Service:** payment-service
**Date:** 2026-07-08
**Severity:** Critical

## Summary
Complete payment service outage for 12 minutes due to a bad deployment
that introduced a null pointer exception on the checkout code path,
triggered on every request regardless of load.

## Timeline
- 16:00 - Deployment v2.3.5 completed
- 16:00 - 100% of payment requests begin failing immediately
- 16:03 - PagerDuty alert fired
- 16:12 - Rollback to v2.3.4 completed, service restored

## Root Cause
A null check was removed during refactoring of the checkout validation
function, causing an unhandled exception on every request.

## Resolution
Immediate rollback. Added mandatory code review checklist item for
null-safety on payment-critical paths.

## Lessons Learned
Payment-critical code paths need mandatory two-reviewer approval and
should never ship without full checkout flow integration tests passing.
